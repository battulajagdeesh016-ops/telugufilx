TELUGUFLIX — PHONE-FIRST ZERO-COST PROTOTYPE

Idi installable website/PWA prototype. Native Android APK kaadu, Play Store app kaadu.
Phone lo browser dwara test cheyochu; HTTPS hosting tarvatha Android Chrome menu lo
"Install app" / "Add to Home screen" option kanipinchavachu.

PHONE LO START:
1. ZIP extract cheyyi (Files app lo).
2. Acode lanti editor lo folder open chesi index.html preview cheyyi.
3. GitHub account create cheyyi: https://github.com
4. GitHub lo New repository -> name: teluguflix -> Public -> Create repository.
5. Add file -> Upload files. ZIP ni kaadu, extract chesina folder lopala unna
   index.html, style.css, app.js, manifest.webmanifest, sw.js upload cheyyi.
6. Settings -> Pages -> Deploy from a branch -> main -> /(root) -> Save.
7. GitHub Pages HTTPS site publish ayyaka Android Chrome lo URL open cheyyi.
8. Chrome menu -> Install app / Add to Home screen (option availability browser batti maarachu).

CURRENTLY WORKING:
- TeluguFlix branded responsive catalogue
- Demo movie/web-series/short-film cards
- Search and category filters
- Details dialog
- Basic PWA manifest and offline cache shell

NOT INCLUDED YET:
- Real video playback, login, database, filmmaker upload/admin portal
- AdMob banner SDK, Google IMA pre-roll/mid-roll ads
- Production backend, content protection, analytics

IMPORTANT:
- Demo titles are placeholders, not real movies.
- Stream only videos you own or have written distribution/streaming permission for.
- Do not paste private keys, passwords, bank details or AdMob account secrets into public GitHub.
- GitHub Pages is for static frontend only. Do not upload copyrighted films or large video files there.
- AdMob is for native apps; this PWA prototype does not earn AdMob revenue.
- A native Android build and Play Store publication need additional build/signing and account steps.
